## 0. 要約

1. **人格を「1 本の英文 + ばらばらの定数」から「特性ベクトル（固定）＋気分（動く）＋技能（学ぶ）」の 3 層に分ける。** 心理学・エージェント研究の定番の分け方（ALMA: 性格 = 長期、気分 = 中期、感情 = 短期）。
2. **学習は「何が儲かるか（技能）」だけにし、「どう選ぶか（流儀）」は特性から決める。** さらに 2 人で **儲けの測り方（効用）を変える**（めたんは損失回避 λ≈2.25、ずんだもんは大勝ちを重く見る）。目的が違えば最適な手も違うので、学ぶほど同じ答えに寄る、が起きにくい。
3. **人格の事前分布への KL の上限と、質問ごとのエントロピーの下限**で「固まり」を防ぐ（今夜のめたんの固まりは、これが無かったのが原因）。
4. **気分（自信・しょんぼり・ドヤ・イラ）を勝ち負けで動かし、減衰させ、判断と一言の両方に戻す。** ずんだもんの「自信 → 失敗 → 泣く → 難しい手に挑戦 → たまに当てる → マウント」が、台本ではなく状態の遷移から出るようにする。
5. **人格が出ているかをログから数える**（質問ごとの偏り、負けた後の振る舞い、助言を聞く率、誰の判断か当てる分類器、一言の繰り返し）。マラソンのたびに回して、目標から外れたら赤を出す。

## 2. 文献から取るもの

質の高い順に、使いどころだけ書く（リンクは本文末の参考文献）。

### 2.1 性格モデルと意思決定のつまみ

- **Big Five と危険選好**: Nicholson ら（2005, *Journal of Risk Research*）は、危険をとる傾向が性格に強く根ざし、外向性・開放性が高く、神経症傾向・協調性・誠実性が低いほど危険をとる、と報告。また危険をとる人を「刺激を求める人」「目標のために負う人」「適応して負う人」に分けた。→ **ずんだもん = 刺激を求める型（高 E・高 O・低 C）、めたん = 目標のために負う型（高 C・低 E）**。めたんも「元が取れると分かれば張る」ので、慎重 ≠ 張らない。
- **プロスペクト理論**（Kahneman & Tversky 1979, *Econometrica*）: 価値は参照点からの増減で測り、損は得の約 2 倍重い（後の推定で λ≈2.25）。→ **損失回避 λ を人格のつまみにする**。めたん λ=2.25、ずんだもん λ≈1。
- **ハウスマネー効果と取り返し効果**（Thaler & Johnson 1990, *Management Science*）: 勝った後は危険をとりやすく、負けた後は「取り返せる」選択肢が特に魅力的になる。→ **ずんだもんの「勝つ → 調子に乗る → 天罰」「負ける → 泣く → もっと難しい手に挑戦」をこの 2 つで出す**。めたんは逆に、負けたら損失回避が強まる（ただしマウントされたときだけ取り返しに走る＝人物像の「慎重策を捨てて外す」）。
- **感情と意思決定**（Lerner ら 2015, *Annual Review of Psychology*）: 感情は判断に系統的に効き、恐れは危険を避け、怒りは危険を軽く見る（評価傾向の枠組み）。→ **めたんのイラ（悔しさ）は危険を軽く見る方向、ずんだもんの落ち込みは短い**。

### 2.2 ゲーム AI のペルソナ

- **手続き的ペルソナ**（Holmgård ら, *IEEE Transactions on Games* 2019）: プレイヤーの型を「何に価値を置くか（効用関数）」として定義し、MCTS の評価を進化させてその効用を最大化するエージェントを作る。型の違いは**目的の違い**で表し、能力（探索）は共通。→ **私たちの「kev の確率（共通の能力）＋人格ごとの効用（目的）」の分け方をそのまま正当化する**。
- **リスク選好の異なる集団**（Jiang ら, AAAI 2024）: 期待値最大化だけの自己対戦は同じ戦略に固まる。リスク水準をハイパーパラメータとして持つ方策（RPPO）を集団で回すと、多様で強い。→ **人格ごとにリスク水準を固定パラメータで持てば、学習しても多様さが残る**。
- **品質多様性（MAP-Elites）**（Mouret & Clune 2015）: 「行動の特徴（記述子）」の格子の各マスで最良の解を残す。→ 直接は使わないが、**「性格の記述子（大胆さ・情報の買い方）を固定したまま、その中で一番儲かる手を学ぶ」**という考え方の土台。
- **感情モデル OCC / ALMA**（Ortony・Clore・Collins 1988、Gebhard 2005, AAMAS）: 出来事を目標に照らして評価して感情（喜び・苦痛・誇り・恥・ほくそ笑み…）を作り、感情が気分を少しずつ動かし、気分は性格で決まる基準点へ戻る。→ **気分の状態と減衰の設計**（4 章）。
- **性格特性がテキストゲームのエージェントに与える影響**（Persona Dynamics, 2025, arXiv）: Big Five の特性を与えたエージェントは、特性に応じて方針と成績が系統的に変わる。→ 特性が「選び方」に出ることの裏づけ（LLM ベースなので参考程度）。

### 2.3 LLM のペルソナ研究（一言・state の英文・評価に効くもの）

- **LLM の性格の測定と整形**（Serapio-García ら, *Nature Machine Intelligence* 2025、arXiv 2307.00184）: 心理尺度（IPIP-NEO）で LLM の性格を測れ、プロンプトで特性ごとに狙った水準へ整形できる（大きい・指示調整済みのモデルほど信頼できる）。→ **特性は「段階つきの形容詞」で書く**と効く。ただし kev は自由文を出さないので、効果は確率の偏りで間接的に測るしかない。
- **ペルソナのぶれ**（Li ら, COLM 2024、arXiv 2402.10962）: 対話が 8 往復ほどで指示されたペルソナから大きくぶれる。原因はシステムプロンプトへの注意の減衰。→ state が長くなる（想起・教訓）ほど前置きが薄まる恐れ。**人格の情報は前置きに一度書くのではなく、各質問の近くで短く繰り返す**、と**人格を判断の外（選び方の層）で強制する**のが堅い。
- **長い対話でのペルソナの持続**（Persistent Personas, 2025, arXiv 2512.12775）: 長いやり取りで人格への忠実さが落ちる。→ 同上。
- **Generative Agents**（Park ら, UIST 2023）: 記憶の流れ（出来事を新しさ・重要度・関連度で取り出す）、振り返り（記憶から高次の気づきを作る）、計画。→ **記憶の重要度（salience）を人格で変える**、**後日談・持ちネタの「前に言ったこと」を記憶から取り出す**。
- **PersonaChat**（Zhang ら, ACL 2018）: 短い人物文を条件にすると、対話の一貫性と魅力が上がる。→ 一言のテンプレートを「人物の事実（金欠・表紙だけ読んだ・77 はラッキーナンバー）」に紐づける。
- **InCharacter**（Wang ら, ACL 2024）: ロールプレイのエージェントに面接形式で性格検査を受けさせ、人が思うその人物の性格と一致するかで忠実さを測る。→ **「人格が出ているか」は人が思う人物像との一致で測る**。私たちの場合は、判断・一言のログから特性を推定して CHARACTERS.md の値と比べる（6 章）。
- **Persona Vectors**（Chen ら, 2025, arXiv 2507.21509）: 性格特性は活性化空間の方向として取り出せ、監視と制御（足し引き）ができる。学習中の性格のずれもこの方向への射影で予測できる。→ kev の重みや活性化には触れないので**今回は採らない**（Ollama 経由の /v1/systemone では不可）。将来、一言用の小さな LLM を入れるときの選択肢として記録。

### 2.4 強化学習で人格を保つ

- **KL 正則化で事前の方策に繋ぎ止める**: Sequence Tutor（Jaques ら, ICML 2017）は報酬で微調整しつつ、元のモデルからの KL で「もとの性質」を保つ。Distral（Teh ら, NeurIPS 2017）は各タスクの方策を共有の事前方策へ KL で寄せる。→ **人格の事前分布（kev × 流儀）からの KL に上限を置き、技能の寄せがそれを超えたら弱める**。
- **エントロピー正則化**（Soft Actor-Critic, Haarnoja ら, ICML 2018）: 報酬にエントロピーを足して、方策が 1 つの手に潰れるのを防ぐ。温度 α がランダムさの強さ。→ **温度とエントロピーの下限を人格のつまみにする**（ずんだもん: 高い温度、めたん: 低い温度だが下限あり）。
- **人格ごとの報酬**: Holmgård のペルソナは効用そのものが人格。RPPO はリスク水準。→ **報酬を人格の効用で変換してから学習器に渡す**（5 章）。

## 4. 気分（動く。出来事で上がり、減衰する）

ALMA の「感情 → 気分 → 性格の基準点へ戻る」を 4 つのスカラーで簡単に持つ（`PersonaMood`、新設の提案。ランの始まりに基準点へ戻す）。

| 気分 | 範囲 | ずんだもんの基準点 | めたんの基準点 | 上がる出来事（OCC の評価） | 下がる |
|---|---|---|---|---|---|
| 自信 `conf` | −1〜1 | **+0.5**（変なところで自信家） | 0.0 | 自分の判断で黒字（誇り）、勘が当たる、配信の序盤でプラス | 赤字、助言を無視して外す |
| しょんぼり `sad` | 0〜1 | 0 | 0 | 大きい赤字（苦痛）、差し押さえ、「だから言ったでしょ」 | 半減期で減衰（ずんだもんは速い） |
| ドヤ `smug` | 0〜1 | 0 | 0 | 相手の反対を押し切って当てた（ほくそ笑み）、相手の読みが外れた | 次の判断ごとに 0.5 倍、天罰で 0 |
| イラ `irk` | 0〜1 | 0 | 0 | めたん: ずんだもんにマウントされた・助言を無視されて当てられた | 当てたら 0、半減期 |

更新（判断の結果 `reward` が出たとき。`g = reward / 基準額`、基準額 = その質問の過去の |reward| の中央値で 0〜±3 に切る）:
- `conf += 0.25·g·(1+N)`（ずんだもんは勝ちで +、負けで − だが、基準点が高いのですぐ戻る）
- 負けたら `sad += 0.4·N·min(1,|g|)`、勝ったら `sad *= 0.5`
- 相談で「押し切って当てた」→ `smug = 0.6 + 0.4·pride`、「押し切って外した」→ `sad += 0.3`、`conf −= 0.3`
- めたん: マウントされた → `irk += 0.5·pride`
- 減衰（判断ごと）: `x ← base + (x − base)·2^(−1/halfLife)`、半減期 = ずんだもん 2 判断・めたん 6 判断（イラは 1 ランに 1 回だけ大きく効かせる）

### 4.1 気分が判断に効く道（流儀の効用、5 章の `S(a)` に足す）

各選択肢に「大胆さ」`b(a) ∈ [0,1]` と「下振れ」`d(a) ∈ [0,1]` をつける（予算・勢い・支援の段階 / 最大、張る側 = demon/hero は 1・none は 0、情報を買わない = 1、新聞を読まない = 0.5 など。いまの `ScoreBias`・`HardRouteChance`・派手な施設の倍率は全部これに吸収できる）。

`S(a) = β_risk·(risk + 0.3·conf + 0.4·smug + 0.5·irk)·b(a) − β_loss·(λ−1)·(cashStress)·d(a) + β_break·sad·hard(a)`

- **ハウスマネー効果**: 勝つと `conf`・`smug` が上がり、大胆さが増す → 次で外しやすい（＝人物像の「4 行目で天罰」がルールではなく確率で起きる）。
- **取り返し効果**: ずんだもんは負けると `sad` が上がり、`hard(a)`（情報を買わずに当てる・魔王軍に全額・派手な施設）への重みが増す → 「泣いた後に難しいところに挑戦」。
  - rules 4.1: `sad` は 2 判断の半減期で配信の判断までに消えるので、負けの後 8 判断（`LossStreakDecisions`）は `sad + 0.4` を取り返しに使い、`β_break = 4`（1.5 では負けた後の hard の率が平常と見分けられなかった: 同じ質問どうしで −4pt → ログの再生で +12pt）。
- **めたんの損失回避**: `cashStress`（返済が近い・現金が少ない）で下振れを強く嫌う。負けた直後は λ が一時的に 1.2 倍（いまは負けても予算が変わらない＝要修正）。
- **めたんが崩れる**: マウントされて `irk` が高い間は、損失回避の項を弱め大胆さを足す。**1 ランに 1 回まで**（人物像「1 本に 1 回」）。外したら `irk=0`、一言は hero（「次は絶対当てる」で外した）。

### 4.2 気分が一言・表情・ミームに効く道

- 一言のキーを `質問|帯` → `質問|帯|気分` に広げる（気分は `conf_high` / `sad` / `smug` / `irk` / `neutral` の最大のもの）。
- 表情: ずんだもんは `conf` 高 → ama/hero、`sad` → namida、`smug` → tsun、迷い（自分の確率が低い）→ hiso。**いまの hiso 54% を 25% 以下に**（聞いたときの hiso は残す）。
- ミーム: 選ぶ重みに気分を掛ける（`smug` → マウント系、`sad` → 泣き系、`conf` → 煽り系）。いまの「結果で smug ×3」をこの形に一般化。

## 5. 性格を保ったまま学ぶ

### 5.1 技能と流儀を分ける

最終の確率（各選択肢 a について）:

`log π(a) = log p_kev(a) + w_skill·Adv_u(a) + S(a)` を温度 τ の softmax で正規化

- `p_kev`: 共通の「能力」（モデルの読み）
- `Adv_u(a)`: 学習器の予測（**人格の効用で変換した損益**、5.2）の advantage（いまの ±上限・縮め・楽観はそのまま）
- `S(a)`: 特性と気分から決まる流儀（4.1）。**学習しない**
- `w_skill = skillRate`（ずんだもん 0.1・めたん 0.6）

いまのめたんの `Careful`（1 位が離れていれば 1 位、近ければ場面で、5% 試す）は、`τ` を小さくした softmax と下の「保険」で置き換えられる（置き換えは任意。リプレイで差を確かめてから）。

### 5.2 人格ごとの効用（報酬の変換）

学習器に入れる前に、損益 x（参照点 = その判断の時点の資産）を変換する:

- めたん: `u(x) = x`（x ≥ 0）、`u(x) = 2.25·x`（x < 0）、さらに分散の罰 `−0.1·|x − 平均|`（金欠で振れが嫌い）
- ずんだもん: `u(x) = sign(x)·|x|^1.15`（大勝ちが嬉しい）、負けは 0.7 倍（素直に泣くが引きずらない＝損から学ばない）

効果: 同じ経験からでも 2 人が学ぶ「良い手」が違う（Holmgård の効用ペルソナ、RPPO のリスク水準と同じ理屈）。**このゲームは大胆な方が平均では儲かる**（周の平均 144 万 vs 92 万）ので、効用を変えないと、めたんは学ぶほどずんだもんに似る。

### 5.3 固まり・収束への保険

1. **人格の事前分布への KL 上限**: `π_prior ∝ p_kev·exp(S)`（技能なし）。`KL(π || π_prior) > ε` なら `w_skill` を二分探索で縮める。ε = めたん 0.35 nat・ずんだもん 0.15 nat（Sequence Tutor / Distral の考え方）。
2. **エントロピーの下限**: kev が 10% 以上つけた手が 2 つ以上ある質問では、`H(π) ≥ H_min`（めたん 0.5 bit・ずんだもん 1.0 bit）を温度を上げて満たす（SAC の考え方）。
3. **「署名の質問」は例外**: めたんの新聞を読む・情報を買う（`intel=true`）は人格そのものなので、偏ってよい（下限をかけない）。表で質問ごとに「署名 / 自由」を指定する。
4. **見張り**: 6 章の指標で、自由の質問の最多の手の割合が 85% を超えたら、次のランは `w_skill` を半分にする（自動の安全弁。ログに出す）。

### 5.4 記憶の重要度を人格で変える

想起・教訓・後日談に使う出来事の重要度:
`salience = |u(x)| × (1 + 感情の強さ) × 人格の重み`
- ずんだもん: 勝った出来事を 2 倍・負けは 0.5 倍（「惜しかったのだ」、学ばない）。教訓は最新 1 件のまま。
- めたん: 「ずんだもんが助言を無視して外した」を 2 倍（「数えてるからね」の材料）、自分の外しは 1 倍。
- 想起の k 件はいまのまま。並び順だけ salience を混ぜる（Generative Agents の新しさ・重要度・関連度）。

## 7. 一言（繰り返しを減らし、人物の芯は守る）

1. **気分つきのテンプレート**: キーに気分を足す（4.2）。テンプレートは 1 キー 6〜10 行を目安に増やす（いまの最多行は「新聞」系で、毎日 1 回聞かれる質問ほど行が足りない）。
2. **繰り返しの抑制**: 行ごとのクールダウン（同じ行は 20 判断あける・1 ラン 3 回まで）、最近使った行の LRU で重みを下げる。
3. **黙る**: 毎日の新聞・同じ判断の連続は「声に出さない」率を上げる（相談の「声に出さない判断」を単独プレイにも）。行を増やすより効く。
4. **記憶からの呼び戻し**: salience の高い出来事を差し込む枠を持つテンプレート（例: ずんだもん「前の 77 個は忘れたのだ」・めたん「この前もそれで外したでしょ」）。出来事の要約は C# 側で数字と言葉の型から作る（LLM なし）。数えるネタは「全額○回目」を使わない（禁止語）。「数えてるからね」「これで何度目かしら」のような言い方にする。
5. **人格の事実に紐づける**（PersonaChat の考え方）: 金欠・表紙だけ・77・ずんだ餅の精、を「事実カード」として行の部品にする。
6. **小さなテキスト LLM（任意・後で）**: VRAM は 12 GB、kev 4B ≈ 8.3 GB・9B ≈ 8.5 GB が常駐するので、**プレイ中に GPU で併走させない**。使うなら
   - (a) 録画後に `consult_to_script.py` の段階で、テンプレートの行を種にして言い換える（CPU でよい、時間制約なし）。入力は人物カード・気分・前後 3 行・禁止語、出力は 48 文字以内・語尾の型を検査、外れたら元の行に戻す。
   - (b) プレイ中にやるなら、kev を CPU にしている録画ランだけ、2〜3B 級の量子化モデルを GPU に（Unity の 1080p 録画と D3D の落ち（2026-10-27）に注意）。まず (a) で質を確かめる。
