# 用語表と口調の基準（画面・会話・データの文言）

画面・会話（宴の CSV）・データ（レリック・設備・アイテム・イベント・村）の文言はこの表にそろえる。
2026-10 の全体ブラッシュアップ（グループ O）で決めた。

## 書式

- 不明な値は全角の「？」1字（「弱点:？」「Lv.？」）。弱点は `ItemAttributeText.Weakness`、属性の字は `ItemAttributeText.ToJapanese`。
- 金額は「12,345G」（3桁区切り、G の前にスペースなし）。
- 三点リーダーは「……」、ダッシュは「――」、感嘆符・疑問符のあとに続けるときは全角スペース「　」。
- 配信中の戦闘の手番（バトルログ・配信熱の「%/ターン」）だけは「ターン」のまま（店の日とは別の単位）。
- 次の配信までは `DayText.UntilStream`（「本日配信」「あと3日」）。見出しを付けるときは「次の配信まで あと3日」、当日は「本日配信」だけにする。
- 確認の結果の色（付箋・記事ポップアップ）: ○ 本物 #2F6E2B、△ 誇張 #A4500E、× 誤報 #A0281C（紙の上で読める濃さ）。

## 物語の枠
