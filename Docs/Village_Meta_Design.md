# 村投資メタ層 企画書（深掘り統合版）

2026-08-30 作成。4系統の深掘り（リファレンス調査 / 組み込み設計 / 経済バランス / 差別化）を統合した設計ドキュメント。
企画意図: **準備シーンの前に「村画面」を追加。ランで稼いだお金を村に投資し、村の発展でレリック解禁や恒常効果が発生する。「村の発展のために店を経営する」物語にする。**

---

## 1. コンセプト（差別化の結論）

> **村は「強くなる場所」ではなく「次のランの市場を自分好みに作り替える場所」にする。**

Moonlighter / Loop Hero / Hades / Rogue Legacy 2 等の拠点メタは全て「プレイヤー側の強化・解禁」。
TomsLands は市場シミュレーション（毎日変動する価格・需要）を持つ唯一のゲームなので、
**メタ投資が「ラン内の市場環境そのもの」を作り替える**構造が、構造レベルで被らない差別化になる。

- 主役: **産業投資**（鉱山→金属系の仕入れ値が下がる、魔法学院→魔法属性の需要が上がる…）＝ メタ投資がビルド宣言になる
- 脇役: 定番の解禁系施設（レリックプール・持ち込み枠・初期レベル等）で「毎ラン何か買える」密度を担保
- 尖らせ方: **村の土地スロットは有限**にし全産業カンスト不可。出資の付け替え（売却・再投資）を許して「株ゲーらしさ」を出す

## 2. リファレンス調査の要点

### 参考にすべき上位3本
| ゲーム | 借りるもの | 借りないもの |
|---|---|---|
| **Moonlighter** | ラン内ゴールドをそのまま村に投資する単一原資 / 投資→村に建物が物理的に建つ演出 / 500G級〜70,000G級の価格勾配 | 「開けたら終わり」の一方通行掲示板（施設には2〜3段階のLvを持たせる） |
| **Loop Hero** | 効果を数値でなく**システム解禁**に寄せる思想（建物=レリック系統・商材・ビルドの解禁キー） | 建材リソース10種の細分化 / 1建物に数ラン分の貯蓄を要求するペース |
| **Rogue Legacy 2** | ラン終了→村→出撃の強制フローを1〜2分で回すテンポ / **失敗ランの稼ぎも村に化ける**敗北の無害化 | +2%系スロットの大量羅列 / 購入ごとの全体価格インフレ |

### 避けるべき失敗パターン（レビュー調査より）
- 用途が競合する複数メタ通貨（Darkest Dungeonの家宝4種）→ **村専用資材は作らない。ゴールドと信用の2通貨のみ**
- 数ラン貯金しないと何も買えない停滞（Loop Hero）→ 毎ラン最低1つ買える価格帯を用意
- 拠点の世話・日課の義務化（Cult of the Lamb / Dave the Diver）→ 村は「ラン間に1回見るだけ」。世話要素は入れない
- 拠点画面に独自操作系を発明してUXが浮く（BALL x PIT）→ 既存の共通UI素材・既存の語彙（投資・配当・信用）を再利用
- 投資1回の変化量が小さい（Cuisineerの床タイル）→ 1購入ごとに「新しい何かが起きる」密度を優先
- 効果が裏で起きて見えない → ラン内で必ず可視化（仕入れ画面に「村: 鉱山Lv2 ▼-8%」バッジ、朝レポートに村の行）
- 「shopkeeper roguelite」はジャンル化が進行中（HAWKER 2026 / Moonlighter 2）。村メタ=市場地形は有効な差別化点

## 3. 画面フロー（村＝ハブ）

```
タイトル（スロット選択=プロフィール）
  ├─ ニューゲーム ──→ VillageScene ──[出撃]──→ PreparationScene ──→ TomsShop(ラン)
  └─ 続きから ──────────────────────────────────────────→ TomsShop(直行・現行どおり)

ラン終了: Result / GameOver → メタ精算 → RunSaveCleaner → VillageScene（現行はタイトル）
          村画面に[タイトルへ]ボタン
```

- **ラン終了後も村へ戻す**のが要点: 「稼いだ金をすぐ注ぎ込む→また出撃」のループが1画面で閉じる。
  Preparation_UnityWiring.md の宿題「もう一度→準備直行」もこれで解消
- 改修は小さい: `TitlePresenter.StartNewGame` の遷移先変更 + `SceneTransitionService.GoToVillage()` 新設
- 買うものがない時は1タップで出撃（スキップ可能）。View未配線時は既存規約どおり素通り→PreparationScene
- **注意**: Result側の精算は「精算→ランデータ削除→遷移」の順序を維持（先に遷移するとランデータ残留バグが再発）

## 4. 通貨設計（全班一致）

| | 信用（既存） | 村資金（新設・G建て） |
|---|---|---|
| 獲得軸 | ランの**上手さ**（ランク・ターン） | ランの**稼ぎ高**（純資産の絶対額） |
| 使途 | 準備画面専用の消耗（借入枠・スタートダッシュ） | 村画面専用の建設資金（恒久解禁） |

- **統合しない**。統合すると「稼ぎ=正義」の一軸に戻り、マンネリの根本原因を再生産する
- 表示も各画面でのみ。将来は借入枠拡張を村の「銀行」施設に移管して信用の役割をさらに絞る選択肢を残す

### 変換ルール（v1）
- クリア時: `村資金 += floor(最終純資産 × 変換率0.5)`（比例のみ・固定ボーナスなし → Short連打周回を自然に抑制）
- 破産時: `村資金 += floor(最終現金 × 0.1)`（RL2型の敗北の無害化。「でも村は育った」）
- **ラン中送金は v1 では入れない**（破産前夜に全額送金→計画破産で持ち逃げ、という悪用の穴が大きい）。
  後続フェーズで「村の行商人」イベント（返済日翌朝限定・手数料付き・1ラン1回）として追加
- **同時改修必須**: `ResultModel` の純資産に金融資産（債券・ファンド）が未算入。村変換の基準にするなら
  `NetWorth += PortfolioModel.TotalAssetsEstimate` を算入しないと「最終日に全解約」が作業最適解になる

## 5. 施設ツリー（v1 叩き台: 定番13 + 産業）

効果の実装型: **[開始時型]**=ラン開始時に一度だけ適用 / **[常時型]**=RelicModifier流用 / **[抽選型]**=プールのフィルタ / **[市場型]**=価格・需要生成への係数注入（シグネチャー）

| 施設 | 効果 | 段階 | 型 |
|---|---|---|---|
| 領主館 | 村の総合Lv。他施設の段階上限をゲート | 3 | - |
| 冒険者ギルド | レリック解禁Tier+1/Lv（`RelicDefinition.unlockGuildLevel`新設→全抽選入口を`RelicRewardService`で一元フィルタ） | 3 | 抽選 |
| 骨董品店 | スターターレリックにRare解禁 | 2 | 抽選 |
| 祠 | レリック3択の選択肢数+1（3→4） | 1 | 開始時 |
| 銀行 | 借入枠テーブル解放段階+1/Lv、Lv3で利息-10% | 3 | 開始時 |
| 倉庫 | 持ち込み枠+1/Lv | 3 | 開始時 |
| 街道整備 | 初期資金+1,000G/Lv | 3 | 開始時 |
| 印刷所 | 開始時フォロワー+500・注目+10/Lv | 2 | 開始時 |
| 職人組合 | 開始時鍛冶屋Lv+1（Lv2で開発費-15%） | 2 | 開始時 |
| 酒場(情報局) | 開始時情報屋Lv+1（=金融商品の初期解禁） | 2 | 開始時 |
| 工房区画 | マシン設置枠+1、Lv2でマシン購入費-15% | 2 | 常時 |
| 農場 | 毎朝+50G/Lv（朝レポートに「村からの収穫」行） | 3 | 常時 |
| 訓練所 | 配信売上+5%/Lv or 敗北時報酬+10% | 2 | 常時 |
| **産業（シグネチャー）**: 鉱山/織物工房/魔法学院/猟師組合… | 対応属性の基準価格係数・需要係数・出現率を恒久変化。**土地スロット有限・付け替え可** | 各2-3 | 市場 |

- 既存レリック23種は Tier0:10 / Tier1:7 / Tier2:6 程度に振り分ければ追加コンテンツなしで解禁の手応えが出る
- 「レリックの種類が増える」は強さでなく**選択肢の広さ**として増やす（初見ランの難易度を変えない）

## 6. 経済バランス（実コード値ベース）

前提実測値: 初期資金10,000G / 借金5,000×1.8^n・7日毎 / 信用獲得 Mediumクリア≒107・S≒252・破産≒20

### コスト曲線の叩き台
| 施設群 | 段階 | 費用例 | 累計 |
|---|---|---|---|
| 酒場（レリック解禁） | 5 | 4,000→60,000 | 126,000 |
| 倉庫（持ち込み） | 3 | 6,000→40,000 | 64,000 |
| 商人ギルド（品揃え） | 3 | 8,000→48,000 | 78,000 |
| 祠（恒常バフ小） | 3 | 10,000→55,000 | 90,000 |
| 合計 | | | **約358,000** |

- 想定村収入/ラン（変換率0.5）: Short C≒6,000 / Medium B≒12,500 / Long S≒30,000 → 平均約12,000
- **製品版: 全解放まで約25〜30周**（体験版: Short中心3〜5周でLv1帯を2〜3施設=「育つ手応え」。酒場Lv2までに制限して引きを作る）

### 効果の強さガイドライン
1. 直接的な収益バフの合計上限は**+15%**（超えるとランク式が自動インフレしS到達が作業化）
2. 主力は「選択肢の拡張」（レリック解禁・持ち込み候補・商材）
3. 初期資金加算系は借金レバレッジと同型の破綻リスク → 大きくしない
4. 任意: 村合計Lvで `debtBaseAmount` +5%/Lv（「発展した村は狙われる」）でパワーインフレを内側から相殺（remote値なので後から有効化可）

## 7. データ・実装設計

- **セーブ**: `metaData.json` に `villageFunds` + `List<FacilityLevelPlain>{facilityId, level}` を追加
  （村専用ファイルは作らない=RunSaveCleaner事故面を増やさない。スロット削除=村も消える現仕様と整合）
- **マスターSO**: `VillageFacilityData`（`Assets/Resources_moved/Village/`・ラベル`VillageFacilityData`・
  `RemoteBalance.ListSections` に `"villageFacilities"` 追加）。レベル毎に cost / RelicModifier[]（常時型）/
  startBonusKey+value（開始時型）/ unlockRelicTier（抽選型）を持つフラット構造
- **スカラー設定**: `GameConstData.villageSettings { conversionRate=0.5, bankruptcyConversionRate=0.1, merchantSendFeeRate=0.2, merchantSendEnabled=false, debtScalePerVillageLevel=0 }`
- **常時効果の配線が肝**: `RelicEffectResolver` のコンストラクタに `permanentModifiers` を追加して集計に合流させるだけで、
  既存の全StatId差し込み点（売上・需要・仕入割引・バズ・配当・金融利回り・陳列枠・借金・製造予算・配信系）を
  **村効果がゼロ改修で使い回せる**。村→ラン間の受け渡しは `VillageEffectService`（metaDataから施設Lvを読みmodifier合成）
- **シーン**: `VillageScene` + `VillageLifetimeScope`（Preparationと同型・null-safe素通りfallback・UIは共通素材流用）

## 8. 実装フェーズ分割

| Phase | ブランチ | 内容 | 単独確認 |
|---|---|---|---|
| V1 コア | `feature/village-core` | SO+生成ツール、MetaProgress拡張、VillageScene骨子、タイトル→村→準備遷移、Result/GameOver→村、純資産→村資金変換（+金融資産の純資産算入修正） | 村画面で投資→スロット跨ぎ永続 |
| V2 開始時効果 | `feature/village-start-bonus` | 初期資金/持ち込み枠/初期Lv/開始フォロワー/借入枠段階 | 施設Lvを変えてニューゲーム→初期値変化 |
| V3 レリック解禁 | `feature/village-relic-unlock` | `unlockGuildLevel`+全抽選入口フィルタ、祠、23種のTier振り分け | ギルドLv0/3で3択の顔ぶれが変わる |
| V4 常時効果 | `feature/village-passive` | Resolver注入、農場（朝レポート統合）、工房区画 | F12で施設Lv操作→売上/朝入金 |
| V5 産業投資 | `feature/village-industry` | **シグネチャー**: 属性別の価格/需要/出現係数、土地スロット、付け替え、仕入れ画面の村バッジ | 鉱山Lv2→金属系の基準価格が下がる |
| V6 送金(任意) | `feature/village-remit` | 「村の行商人」イベント（返済日翌朝限定・手数料20%・1ラン1回） | 送金→村資金反映 |

V1〜V2 で「村に投資すると次のランが強くなる」ループが成立するので、そこで一度プレイ確認を挟む。
