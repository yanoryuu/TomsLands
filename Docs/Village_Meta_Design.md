  Lv5 のときは「現在」に Lv4 の効果文（数値の効果は Lv4 のまま続く）を出す。建物の見た目は Lv3 の絵のまま（Lv4・Lv5 の段階絵は未作成）。
- 占い師の値段は `ProphetFortune.CurrentCost`（= `VillageEffects.ApplyProphetPrice(15,000G)`）を支払いと表示の両方で使う。
- 領主館の完走ボーナスの上乗せは `MetaProgressModel.CalculateVillageFunds` の完走ボーナスに掛かる（`hallClearBonusRates`）。
- 削除: 倉庫（持ち込みアイテムは廃止済み）・街道整備・農場。統合: 骨董品店・祠→冒険者ギルド、工房区画→職人組合、印刷所・訓練所→広場。
- 効果の数値は `GameConst.Village`（`VillageSettingsData`。配信値で調整可）。施設レベルから効果を決めるのは `VillageEffects`（Assets/Scripts/Village/VillageEffects.cs）。
  効果文（effectText）は表示だけで、数値は持たない。
- レリックの解禁段階は `RelicDefinition.unlockGuildLevel`（§11-A の Tier どおり。呪い2種は抽選外のまま）。報酬の3択（`RelicRewardService`）とスターター候補（準備画面）の両方に効く。
- 既存セーブの読み替え（`VillageFacilityMigration`。metaData.json の読み込み時に1回）: 統合元のレベルを統合先のレベルに読み替える（統合先 = max(統合先, 統合元)）。
  統合先が上がらなかった分・削除した施設は、旧マスターシートの建設費で村資金へ返金する。
  最大レベル（Lv5。`VillageFacilityMigration.MaxFacilityLevel`）を超えた分も返金するが、Lv5 化のあとは超えるセーブは無い
  （Lv3 時代のセーブの施設 Lv0〜3 はそのまま読める。以前「最大 2」で返金していた領主館 Lv3 も、今は Lv3 のまま残る）。

### 0-2. ラン終了 → 村資金

- **儲け = 純資産 − 初期資金 − 持ち込み − 立て替え**（`RunProfit`）。持ち込みはラン開始時に `RunHistory` へ記録し、立て替え（チュートリアルの 50,000G）はそのランで受け取った場合だけ引く。
- クリア: 村資金 += 持ち込み（儲けが赤字ならその分を引いた残り）＋ 完走ボーナス ＋ max(0, 儲け) × 変換率 × 難易度倍率
  - 変換率 `conversionRate` = 25、難易度倍率 `difficultyConversionMultipliers` = かんたん 1.0 / ふつう 1.2 / むずかしい 1.4
  - 完走ボーナス `clearBaseFunds` = 30万 / 45万 / 60万（赤字のクリアでも Lv1 を1つ建てられる額）
- 破産: 持ち込みは戻らない。そのランでいちばん儲かっていたとき（所持金の最高値から求める）の儲け × 変換率 × 難易度倍率 × `bankruptcyConversionRate`(0.2)。
- 数値の根拠（AutoPlay ヘッドレス、各8シード）は §0-4。

### 0-3. ランクと記録

- ランク = 儲け ÷ 難易度別の基準 `rankBaseProfits`（かんたん 6万 / ふつう 13万 / むずかしい 22万）。S = 基準×2 以上、A = 基準以上、B = 基準×0.4 以上、C = 黒字、D = 赤字。
- metaData.json に、難易度ごとの最高の儲け（`bestProfits`）と直近20ランの履歴（`runRecords`: 難易度・クリア/破産・儲け・純資産・ランク・ターン・討伐/防衛・配信の収支・村へ入った額・日時）を残す。
- リザルトの左パネル: 最終金額 / 儲け / 商品金額 / 合計 / 周回（N周目・Tターン） / 自己ベスト（更新したら「更新！」を金色で） / 村へ（入る村資金）。
  配信のカードは「討伐N・防衛M」と配信の収支の合計。
- 破産画面: 配信の成績・持ち込みが戻らないこと・村へ入る額、トコ（06_泣き）。ボタンは「村へ戻る」1つ。

### 0-6. Lv5 の特殊な効果: 銀行「勝負の融資」・広場「勝負配信の宣言」（2026-10-21）

どちらも1ランに1回。使ったかどうか・決着待ちの状態はランのセーブ（tomsData.json。`RunSaveCleaner` で消える）に置く。古いランのセーブは欠損＝未使用として読む。
使わなければ何も起きない（確認のポップアップで「今回は使わない」を選べる）。数値は `GameConst.Village`（`bankLoanInterestRate`・`plazaDeclaration*`）。

**銀行 Lv5「勝負の融資」**（`Assets/Scripts/Debt/BankLoan.cs`・`DebtPresenter`）
- 出す時: **配信の前日の朝**、朝の通知の最後にポップアップ「勝負の融資」（借りる／今回は使わない）。断ったらその配信の前には出し直さず、次の配信の前日にまた出す。
  前日に出すのは、店の1日まるごと（仕入れ・陳列・魔王軍支援・取引所）に使えるようにするため（配信日の寄り道は鍛冶屋だけ）。
- 額: 持ち込み上限の最後の値（`bankCarryLimits` の末尾、今は 70万G）。返す額 = 元本 × (1 + 利息1割) = 77万G。
- 返す日: **配信の次の日の朝**。通常の納付と同じ強制のパネル（見出し「融資の返済日！」・「返済額」）で、現金が足りなければ納付と同じく
  今日の売上の前倒し → 金融資産の強制売却 → 在庫の投げ売り → それでも足りなければ破産。納付と同じ朝なら納付のあとに出す。レリック3択は付かない。
- 見え方: 店ホームの納付の表示は、融資の返す日が次の納付より先なら「融資の返済／77万G／あと2日」、同じ日なら「納付＋融資」で合計額。借りた瞬間に表示が弾む（`UIFx.Pop`）。
  配信日の寄り道のポップアップに「融資: 770,000G を N日目に返す」。朝レポートの総資産は返す額を引いて数える。
- 儲け: 返し終えていれば所持金から引かれ済み（利息の分だけ儲けが減る）。最後の配信の前日に借りて返す日が来ないまま終わったら、決算の純資産から返す額を差し引く（`ResultModel`）。
  破産時の「いちばん儲かっていたとき」は、借りていた日の所持金から返す額を引いて数える（`RunProfit.ComputePeak`・`RunHistory` の `bankLoan*`）。二重には引かない。

**広場 Lv5「勝負配信の宣言」**（`Assets/Scripts/Village/StreamDeclaration.cs`・`PreStreamPresenter`・`BattleSceneStarter`・`BattleResultHandler`）
- 出す時: 配信日、配信前の寄り道の最初。「勝負配信の宣言」（宣言する／今回は使わない）→「どちらが勝つ？」（勇者が勝つ／魔王が勝つ）→ 確認（宣言する／やめる）→ いつもの「今日は配信日」。
  確認を挟むのは、2つ目のポップアップの B/Esc がキャンセル（＝魔王が勝つ）に当たるため。宣言したら「今日は配信日」の本文に「宣言: 勇者が勝つ」。
- 当たり（勇者が勝つ＆勝利／魔王が勝つ＆敗北）: 配信の売上と防衛報酬の合計 ×（1.5 − 1）を純利益に上乗せ（配信リザルトに「宣言的中 ×1.5」の行）、
  フォロワー +6,000・注目 +100。決着の帯のあとに「宣言的中！」の帯（勇者側は金・魔王側は紫。`BattleWaveFxView.PlayBannerAsync`）。
- 外れ: フォロワー -2,000・注目 -60（配信リザルトに「宣言 外れ」の行）。
- 途中終了（Abort）: 宣言は無効（「宣言 無効」の行）。配信終了ボタンでの途中終了は回数を使ったまま（決着から逃げる手にしない）、不具合での途中終了は回数を戻す。
- 広場 Lv2〜4 の「配信の売上 +15%」は今までどおり帰還処理で別に足す（宣言の ×1.5 とは掛け合わせない）。
- 自動プレイ（DebugAutoPlayer）は宣言・融資のポップアップで「今回は使わない」を選ぶ。

## 1. コンセプト（差別化の結論）

> **村は「強くなる場所」ではなく「次のランの市場を自分好みに作り替える場所」にする。**

Moonlighter / Loop Hero / Hades / Rogue Legacy 2 等の拠点メタは全て「プレイヤー側の強化・解禁」。
TomsLands は市場シミュレーション（毎日変動する価格・需要）を持つ唯一のゲームなので、
**メタ投資が「ラン内の市場環境そのもの」を作り替える**構造が、構造レベルで被らない差別化になる。

- 主役: **産業投資**（鉱山→金属系の仕入れ値が下がる、魔法学院→魔法属性の需要が上がる…）＝ メタ投資がビルド宣言になる
- 脇役: 定番の解禁系施設（レリックプール・持ち込み枠・初期レベル等）で「毎ラン何か買える」密度を担保
- 尖らせ方: **村の土地スロットは有限**にし全産業カンスト不可。出資の付け替え（売却・再投資）を許して「株ゲーらしさ」を出す

## 2. リファレンス調査の要点

### 参考にすべき上位3本
| ゲーム | 借りるもの | 借りないもの |
|---|---|---|
| **Moonlighter** | ラン内ゴールドをそのまま村に投資する単一原資 / 投資→村に建物が物理的に建つ演出 / 500G級〜70,000G級の価格勾配 | 「開けたら終わり」の一方通行掲示板（施設には2〜3段階のLvを持たせる） |
| **Loop Hero** | 効果を数値でなく**システム解禁**に寄せる思想（建物=レリック系統・商材・ビルドの解禁キー） | 建材リソース10種の細分化 / 1建物に数ラン分の貯蓄を要求するペース |
| **Rogue Legacy 2** | ラン終了→村→出撃の強制フローを1〜2分で回すテンポ / **失敗ランの稼ぎも村に化ける**敗北の無害化 | +2%系スロットの大量羅列 / 購入ごとの全体価格インフレ |

### 避けるべき失敗パターン（レビュー調査より）
- 用途が競合する複数メタ通貨（Darkest Dungeonの家宝4種）→ **村専用資材は作らない。ゴールドと信用の2通貨のみ**
- 数ラン貯金しないと何も買えない停滞（Loop Hero）→ 毎ラン最低1つ買える価格帯を用意
- 拠点の世話・日課の義務化（Cult of the Lamb / Dave the Diver）→ 村は「ラン間に1回見るだけ」。世話要素は入れない
- 拠点画面に独自操作系を発明してUXが浮く（BALL x PIT）→ 既存の共通UI素材・既存の語彙（投資・配当・信用）を再利用
- 投資1回の変化量が小さい（Cuisineerの床タイル）→ 1購入ごとに「新しい何かが起きる」密度を優先
- 効果が裏で起きて見えない → ラン内で必ず可視化（仕入れ画面に「村: 鉱山Lv2 ▼-8%」バッジ、朝レポートに村の行）
- 「shopkeeper roguelite」はジャンル化が進行中（HAWKER 2026 / Moonlighter 2）。村メタ=市場地形は有効な差別化点

## 3. 画面フロー（村＝ハブ）

```
タイトル（スロット選択=プロフィール）
  ├─ ニューゲーム ──→ VillageScene ──[出撃]──→ PreparationScene ──→ TomsShop(ラン)
  └─ 続きから ─┬─ 進行中のランあり ───────────────────────→ TomsShop(直行)
               │    （前回が配信中・配信前の寄り道中なら FightScene で配信をやり直す／リザルト前なら ResultScene）
               └─ 村の進行だけ（ラン終了後）──→ VillageScene

ラン終了: Result / GameOver → メタ精算 → RunSaveCleaner → VillageScene（現行はタイトル）
          村画面に[タイトルへ]ボタン
```

## 4. 通貨設計（全班一致）

| | 信用（既存） | 村資金（新設・G建て） |
|---|---|---|
| 獲得軸 | ランの**上手さ**（ランク・ターン） | ランの**稼ぎ高**（純資産の絶対額） |
| 使途 | 準備画面専用の消耗（借入枠・スタートダッシュ） | 村画面専用の建設資金（恒久解禁） |

- **統合しない**。統合すると「稼ぎ=正義」の一軸に戻り、マンネリの根本原因を再生産する
- 表示も各画面でのみ。将来は借入枠拡張を村の「銀行」施設に移管して信用の役割をさらに絞る選択肢を残す

### 変換ルール（v1）
- クリア時: `村資金 += floor(最終純資産 × 変換率0.5)`（比例のみ・固定ボーナスなし → Short連打周回を自然に抑制）
- 破産時: `村資金 += floor(最終現金 × 0.1)`（RL2型の敗北の無害化。「でも村は育った」）
- **ラン中送金は採用しない**（2026-08-30 ユーザー決定。破産前夜に全額送金→計画破産で持ち逃げという悪用の穴があり、
  村と店の経営のフロー分離の原則にも反するため）
- **同時改修必須**: `ResultModel` の純資産に金融資産（債券・ファンド）が未算入。村変換の基準にするなら
  `NetWorth += PortfolioModel.TotalAssetsEstimate` を算入しないと「最終日に全解約」が作業最適解になる

- **施設区画**: 各施設は固定区画を持ち、見た目が **空き地（立て札）→ 建設中（足場）→ Lv1〜3の建物** と段階変化。
  投資した瞬間にその場で建設演出（DOScaleポップ+土煙）が入る＝「建っていくのが見える」の核
- **インタラクション（新規・小規模）**: 施設区画に `Collider2D(Trigger)` を置き、プレイヤーが近づくと頭上に
  「調べる」吹き出し＋施設名を表示 → 決定キー/タップで**投資パネル**（共通素材の6枠ポップアップ:
  現Lv効果/次Lv効果/費用/[投資する]）を開く。未解禁区画は「領主館Lv2で解禁」の立て札
- **出撃**: 村の出口（馬車/門）に近づいて決定 → PreparationScene へ。加えて**画面隅に常設の[出撃]ボタン**も置き、
  歩きたくない周回時は1タップで出られるようにする（1〜2分テンポ厳守の保険）
- **HUD**: 上部に村資金/信用/村総合Lv（常時表示・薄めの帯）。[タイトルへ]はメニュー内

### 13-B. 帰還演出
- 受け渡しは消費型（ConsumeLastBuzzResultパターン）。村ロード0.5秒後に「収支報告」ポップ:
  クリア「今回の稼ぎ 25,000G → 村へ +12,500G」DOTweenカウントアップ→村資金パンチスケール。
  破産「手元に残った 800G → 村へ +80G」+一言（それでも村は待っている）
- 初回（totalRuns==1）のみ村長の説明3クリック。2回目以降はポップのみ・タップ即閉じ（1〜2分テンポ厳守）
- 閉じた直後、新たに買える施設行に「建設可」バッジ点灯

### 13-C. 投資インタラクション
施設に接近→吹き出し→決定で投資パネル（現Lv効果/次Lv効果/費用、資金不足はdisable+赤、未解禁は解禁条件表示）→[投資する]→SE開発完了→**その場で建物が段階変化する建設演出**（DOScale OutBack+土煙）→パネルは次Lv表示へ。10,000G超のみPopUpManager確認。連続投資可。

### 13-F. 村人（2026-08-30 ユーザー決定: 村人も歩かせる）

- **発展連動の移住**: 施設を建てるたびに対応する村人が移住して村を歩き出す
  （冒険者ギルド→冒険者、農場→農夫、銀行→銀行員、酒場→情報屋の弟子…）。
  「投資→建物が建つ→人が増える」の二段の実感で、発展の可視化を建物+人口の両輪にする
- **挙動**: 配信画面の `CustomerCharacter`（SPUMキャラ+歩行ボブ+目的地移動）を流用した `VillagerCharacter` を新設:
  区画間のウェイポイントをランダム徘徊→数秒立ち止まる→また歩く、のループのみ（〜100行規模）。
  **世話・欲求・スケジュールは絶対に入れない**（Cult of the Lamb型の作業感地雷を回避。村人=発展の擬人化に徹する）
- **話しかけ（軽量）**: プレイヤーが接触すると一言吹き出し。基本はフレーバー、たまに実用ヒント
  （例:「最近、火の武具がよく売れるらしい」=市場・産業のヒント）。セリフはScriptableObjectのテーブルで拡張可能に
- **キャラ絵**: SPUM資産で生成（新規アート発注なし）。V1は汎用村人2〜3人が徘徊するだけでも村が生きて見える
- **段階導入**: V1=汎用村人2〜3人の徘徊のみ / V2以降=施設連動の移住+話しかけ一言 / 将来=Live2D・固有村人
