# 全画面 UI再構築プロンプト集（claudeDesign 用）

TomsLands の全画面を、提供素材を使ってインタラクティブHTMLモックとして作り直すための
ビルドプロンプト集。**別Claude（claude.ai のアーティファクト等）に渡して使う**前提。

## 使い方
1. まず下の **【共通プロンプト】** を貼る。
2. 続けて作りたい画面の **【画面別ブリーフ】** を1つ貼る。
3. 素材（キャラ立ち絵 / UIフレーム・ボタン素材 / 背景画像）を**添付**する。
4. 1画面ずつ作る（まとめて投げると精度が落ちる）。

> 仕入れ画面(BlackSmith)だけは別ファイル `Docs/ProcurementMock_BuildPrompt.md` に詳細版あり。

---

# 【共通プロンプト】（毎回先頭に貼る）

```
あなたはファンタジーRPGショップ運営ゲーム「TomsLands」のUIを作るデザイナーです。
これから指定する1画面を、添付素材を使って「インタラクティブHTMLモック」として Artifact で作ってください。

## 守ること（全画面共通）
- 単一の自己完結HTML（CSS/JSインライン）。外部URL・CDN・外部フォント禁止。
- 添付画像は data: URI（base64）でインライン埋め込みして使う。
- 文言は日本語。横長デスクトップ画面想定（16:9）。
- ページ自体は横スクロールさせない（はみ出すものは内部だけスクロール）。
- 独自の派手な装飾は足さない。添付UI素材（フレーム/ボタン/背景）の見た目を主役にする。
- 素材の割り当て:
  - 背景画像 → ページ全体の背景。
  - UIフレーム・ボタン素材 → パネル枠・タブ・ボタンに適用（角が伸びる素材は CSS border-image で9-slice的に）。
  - キャラ立ち絵 → 各ブリーフで指定する位置に配置（多くは左サイドに店主、上に会話フキダシ）。
  - アイテム/アイコン類で素材が無いものは、属性カラー縁取りのグレー枠プレースホルダーで代用。
- 属性カラー: 火=赤 / 水=青 / 雷=黄 / 風=緑 / 土=茶 / 光=白金 / 闇=紫。
- 完成したらクリック等の動作が効くことを確認し、未割り当て素材があればどこか教えて。

この後に「画面ブリーフ」を渡します。そのレイアウト・要素・操作仕様どおりに作ってください。
```

# 【画面別ブリーフ】

各ブリーフは「目的／レイアウト／要素／操作／キャラ配置／サンプルデータ」で構成。

---

## A. 店内ハブ・ターン進行系

### A-1. ホーム画面（トムの店ハブ）
- **目的**: 各画面への入口。ターンのフェーズ進行の起点。
- **レイアウト**: 背景の上に、中央〜手前に商品陳列の机（カルーセル）。左に店主キャラ＋会話。下部または右に次回返済情報。上部にターン番号表示。
- **要素**:
  - ナビゲーションボタン: 鍛冶屋 / ヒーロー / 商品陳列 / 情報屋 / 道具屋 / 営業開始 / マップ / ダンジョン強化 / 広告 / 預言者 / 借金返済
  - 商品陳列の机（今売り出し中アイテムのアイコンが並ぶ）
  - 「次回返済 ●●G　あと●ターン」テキスト＋返済ボタン
  - フェーズ表示ラベル（イベント/仕入れ/商品陳列/営業）と「次へ／スキップ」ボタン、フェーズ別ボタン群の出し分け
- **操作**: 各ボタンで対応画面へ。フェーズに応じてボタン群が切り替わる。営業開始でターン消化。
- **キャラ配置**: 左に店主立ち絵＋フキダシ「いらっしゃい！今日はどうする？」
- **サンプル**: 所持金 12,000G / ターン 5 / 次回返済 3,000G あと2ターン。

### A-2. ターン終了サマリー
- **目的**: 営業結果（売上）の報告。
- **レイアウト**: 中央にカード。上にグレード、下に明細リスト、最下部に確認ボタン。
- **要素**: グレード画像(S/A/B/C/D/E)＋コメント / 合計売上(G) / 売れた個数 / 次の戦闘まで残り日数 / 明細行（アイテムアイコン・名前・売れた数・売上）/ 確認ボタン。
- **操作**: 確認で次フェーズへ。
- **キャラ配置**: 右下に店主の小さなリアクション立ち絵（任意）。
- **サンプル**: グレードA「上々だね！」/ 売上 8,400G / 22個 / 次の戦闘まで2日。明細: 火の剣×3 360G、鉄の鎧×4 440G…。

### A-3. イベントポップアップ
- **目的**: 数ターンに一度の良い/悪いイベント告知。
- **レイアウト**: 画面中央のモーダル。タイトル＋本文（ページ送り）＋確認ボタン。
- **要素**: イベントタイトル / 本文(複数ページ) / 効果テキスト / 確認(次へ)ボタン。
- **操作**: クリックでページ送り→最終で効果表示→閉じる。
- **キャラ配置**: 左下に店主立ち絵（驚き/喜び表情想定）。
- **サンプル**: 「街に行商人がやってきた！」→「武器の需要が上昇した！(火属性 需要+15%)」。

## B. 仕入れ・陳列・経済系

### B-1. 仕入れ画面（鍛冶屋／トレード端末）
→ 詳細は別ファイル `Docs/ProcurementMock_BuildPrompt.md` を使用（株トレード端末風：上部に次ダンジョンバナー、左に店主、中央に銘柄一覧、右に詳細＋価格チャート＋注文）。

### B-2. 商品陳列画面
- **目的**: 在庫から「売り場に並べる」アイテムを選ぶ。
- **レイアウト**: 左に在庫一覧（タブ:武器/防具/道具）、右に売り場(陳列スロット)。中央下にアイテム説明。
- **要素**: 在庫リスト行（アイコン・背景・名前・価格・在庫）/ 陳列リスト（アイコン＋数量）/ おすすめ陳列ボタン / 閉じる。
- **操作**: 在庫をクリック→売り場へ追加 / 陳列スロットをクリック→撤去 / タブで種別フィルタ / おすすめ陳列で自動配置。
- **キャラ配置**: 左下または右下に店主（任意）。
- **サンプル**: 在庫: 火の剣120G ×3 / 鉄の鎧110G ×4 …。陳列枠 最大8。

### B-3. 広告購入画面
- **目的**: 配信の広告を買い、各ステータスを伸ばす。
- **レイアウト**: 上に現在ステータス、左に広告一覧、右に選択広告の効果プレビュー。
- **要素**: ステータス表示(信頼/注目/拡散/維持/フォロワー、各 現在/最大)＋各infoボタン / 広告リスト行(アイコン・名前・費用・効果プレビュー) / 選択枠ハイライト / 閉じる。効果プレビューは +X を緑/赤で。
- **操作**: 広告クリックで効果プレビュー＆選択。infoで説明ツールチップ。
- **キャラ配置**: 右に店主 or マネージャー風キャラ（任意）。
- **サンプル**: 信頼60/100、注目40/100、フォロワー1,200。広告「SNS拡散」費用800G 効果: 拡散+10 注目+5。

### B-4. 預言者（市況予測）
- **目的**: トレンド・価格ランキング・次ダンジョンおすすめを占う。
- **レイアウト**: 4セクション。左に預言者キャラ＋セリフ、右に①トレンド上位②価格ランキング③次ダンジョン情報④おすすめ装備。
- **要素**: トレンド行(アイコン・名前・Trend・需要%) / 価格ランキング行(順位・アイコン・名前・価格) / 次ダンジョン(名前・弱点属性・難易度・残ターン・アイコン) / おすすめ装備行(同属性、おすすめ度順)。
- **操作**: 行ホバーで予言者のセリフ変化、キャラクリックで雑談。
- **キャラ配置**: 左に預言者立ち絵＋フキダシ（必須）。
- **サンプル**: トレンド: 雷の斧/光の聖衣/火の剣。次ダンジョン: 火の洞窟 弱点:火 あと2ターン。おすすめ: 炎耐性マント/火の剣。

## C. 冒険・情報系

### C-1. マップ画面
- **目的**: 挑むダンジョンを選ぶ。
- **レイアウト**: 背景マップ上に6つのダンジョンアイコンを配置。戻るボタン。
- **要素**: ダンジョンアイコン6つ（忘却の霊廟/灼熱の火山/氷霧/深緑の獣/古代機械/魔王城）。状態表示(クリア/失敗/未踏=バウンド演出)。戻る。
- **操作**: アイコンクリックで詳細/選択。戻るでホーム。
- **キャラ配置**: なし（マップ主役）。任意で隅にガイドキャラ。
- **サンプル**: 火山=未踏、霊廟=クリア済、氷霧=失敗。

### C-2. ダンジョン詳細
- **目的**: 選択ダンジョンの情報とモンスター一覧（情報購入済みのみ）。
- **レイアウト**: 中央パネル。上に名前画像＋アイコン、中に説明/レベル/報酬、下にモンスター一覧。
- **要素**: ダンジョン名 / アイコン / レベル / 説明 / 報酬(未購入は「？？？」) / モンスタースロット群 / 閉じる。
- **操作**: 閉じるで戻る。
- **キャラ配置**: なし。

### C-3. ダンジョン強化
- **目的**: ダンジョンをレベルアップして報酬・難度を上げる。
- **レイアウト**: 左にダンジョン一覧(縦)、右に詳細パネル(名前・レベル・報酬・現/次モンスター)。
- **要素**: ダンジョン強化スロット / 詳細(現レベル→次レベル、費用、現モンスター行、次モンスター行) / キャラ＋セリフ / 閉じる。
- **操作**: スロット選択で詳細更新。強化で費用消費。
- **キャラ配置**: 左下に案内キャラ（任意）。

### C-4. 情報屋
- **目的**: ダンジョン情報・ヒーロー情報を購入。
- **レイアウト**: タブ式モーダル。左に情報屋キャラ＋セリフ、右にタブ内容(マップ情報/ヒーロー情報)。
- **要素**: タブボタン / ダンジョン情報購入リスト(アイコン・名前・費用=ターン連動) / ヒーロー情報(Lv/HP/装備/クリア確率 or 「？？？」)＋購入ボタン / 閉じる。
- **操作**: タブ切替。購入で情報解放。
- **キャラ配置**: 左に情報屋立ち絵＋フキダシ（必須）。
- **サンプル**: 火の洞窟の地図 500G / 勇者の情報 800G。

### C-5. ヒーロー編成
- **目的**: 勇者の装備・戦術を設定し、クリア確率を確認。
- **レイアウト**: 左に勇者立ち絵＋装備アイコン、右にステータスと3ドロップダウン(武器/防具/戦術)。下にクリア確率と説明。
- **要素**: ステータス(Lv/EXP/HP/MP/攻/防) / 武器・防具・戦術ドロップダウン / 装備アイコン / クリア確率%(情報未購入なら「情報未購入」) / 4つのinfoボタン(ホバー説明) / 会話 / 閉じる。
- **操作**: ドロップダウン変更で装備反映。infoホバーで説明。
- **キャラ配置**: 左に勇者立ち絵（必須）。
- **サンプル**: 勇者Lv.5 HP120 攻35 防20。武器:火の剣 防具:鉄の鎧 戦術:バランス。クリア確率 68%。

## D. タイトル・セーブ・結果系

### D-1. タイトル画面
- **目的**: メインメニュー（開始/難易度/セーブ選択）。
- **レイアウト**: 4ステップ画面。①開始(タイトルロゴ＋STARTボタン) ②方式(新規/つづき/戻る) ③難易度(やさしい/ふつう/むずかしい/戻る) ④セーブ選択(スロット一覧/戻る)。
- **要素**: タイトルロゴ(拡縮アニメ) / 各ボタン群 / セーブスロット一覧。
- **操作**: STARTで方式へ→新規/つづき→難易度→セーブ選択。
- **キャラ配置**: 背景にキャラ大きく配置可（タイトル映え重視）。
- **サンプル**: 難易度3種、スロット3つ。

### D-2. セーブスロット（タイトル内の各スロット）
- **目的**: 1スロットの概要表示／選択／削除。
- **レイアウト**: 横長カード。左にスロット番号、中に概要、右に選択/削除ボタン。
- **要素**: 「スロット1」 / 概要「ふつう Day5 1,200G」 or 「空き」 / 選択ボタン(空きならロード時は無効) / 削除ボタン(データありのみ)。
- **操作**: 選択でロード/新規、削除で消去。
- **キャラ配置**: なし。
- **サンプル**: スロット1=ふつう Day5 1,200G / スロット2=空き / スロット3=むずかしい Day12 8,500G。

### D-3. リザルト画面
- **目的**: 周回の総決算（ランク・資産・成長）。
- **レイアウト**: 中央に大きくランク、下に数値群、最下部に2ボタン。
- **要素**: ランク(S/A/B/C/D、色分け) / 最終所持金 / 増減(緑=黒字/赤=赤字) / 在庫評価額 / 純資産 / 総ターン数 / 鍛冶屋レベル / 情報屋レベル / タイトルへ・リトライ。
- **操作**: タイトルへ / リトライ。
- **キャラ配置**: 右下に店主の達成リアクション（任意）。
- **サンプル**: ランクA / 最終12,400G(+8,400) / 純資産18,900G / 総24ターン。

### D-4. ゲームオーバー
- **目的**: 借金返済不能の終了画面。
- **レイアウト**: 中央にタイトル＋メッセージ＋ターン、下に2ボタン。暗いトーン。
- **要素**: 「借金返済不能！！」/「お店が差し押さえられてしまいました！」/「ターン●で力尽きました…」/ リトライ・タイトルへ。
- **操作**: リトライ / タイトルへ。
- **キャラ配置**: 中央〜下に店主の落胆立ち絵（任意）。

### D-5. 借金返済
- **目的**: 返済日の支払い（不能なら破産）。
- **レイアウト**: 中央モーダル。支払いパネルと破産パネルの2状態。
- **要素**: 「第●回 借金返済日！」/ 返済額 / 所持金 / 不足テキスト(払えない時) / 支払うボタン(不足で無効) / 閉じる。破産パネル: 破産メッセージ＋リザルトへ。
- **操作**: 支払う / 閉じる / リザルトへ。
- **キャラ配置**: 借金取りキャラ（任意・威圧的に）。
- **サンプル**: 第3回返済 5,000G / 所持金 3,200G（不足）。

## E. 戦闘・配信系（FightScene）

### E-1. 配信バトル画面（メイン）
- **目的**: 勇者がダンジョン攻略する様子を「配信」しながら、視聴者へ商品を売る。
- **レイアウト**: 背景＝ダンジョン。中央に勇者＆敵キャラ。上部に配信熱ゲージ。左or下に売り場(出品アイテム)、右or上に売上表示。操作ボタン(一時停止/終了)。
- **要素**:
  - キャラ表示(勇者/敵のスプライト＋HP/MP＋ダメージポップ)
  - 配信熱ゲージ(横バー＋ティア名＋価格変動方向 ▲緑/▼赤/−灰)
  - 売上表示(合計G＋出品アイテムスロット:アイコン・在庫)
  - 出品アイテムスロット(ドラッグ&ドロップで売り場へ、ホバーで価格目安＋矢印、クリックで価格グラフ)
  - ステマボタン(基本/集中)＋コスト・クールダウン
  - 一時停止/再開・戦闘終了ボタン、再仕入れ確認ポップアップ
- **操作**: アイテムをドラッグして売り場へ→販売、クリックで価格グラフ、ステマで需要操作、一時停止。
- **キャラ配置**: 戦闘キャラが主役（立ち絵ではなくバトルスプライト）。配信者アバターを隅に置くのは任意。
- **サンプル**: 熱ゲージ「盛り上がり中！」▲+8%/ターン。売上 4,200G。出品: 火の剣 在庫3 / 回復薬 在庫5。

### E-2. 価格グラフ（バトル中のポップアップ）
- **目的**: アイテムの価格推移を折れ線で確認。
- **レイアウト**: 中央パネル。上にアイテム情報、中に折れ線グラフ、閉じる。
- **要素**: アイコン・名前・現在価格・変化量(色) / 折れ線(点=緑↑/赤↓/黄—、価格ラベル、ターン＋増減) / 軸線 / 閉じる。
- **キャラ配置**: なし。

### E-3. 配信リザルト
- **目的**: 戦闘後の勝敗＋売上報告。
- **レイアウト**: 中央。勝敗タイトル＋売上＋売れたアイテム一覧＋確認。
- **要素**: 「勝利！」/「敗北…」/ 売上G / 売れたアイテム(アイコン＋数) / 確認。
- **キャラ配置**: 勝敗に応じた勇者/店主リアクション（任意）。

### E-4. 出品設定（戦闘前）
- **目的**: 戦闘に持ち込む出品アイテムと数量を選ぶ。
- **レイアウト**: 左に在庫(出品可能)一覧、右に選択中リスト(数量スライダー)。下に確認/前回と同じ/自動選択。
- **要素**: 在庫スロット(名前・アイコン・在庫) / 選択中スロット(アイコン・名前・数量スライダー・削除) / 確認・「前回と同じ(●種)」・自動選択。
- **操作**: 在庫クリックで追加、数量調整、削除、確認で開始。
- **キャラ配置**: 左下に店主（任意）。
- **サンプル**: 出品可能: 火の剣 在庫3 / 回復薬 在庫5。選択: 火の剣×2、回復薬×3。

## F. オーバーレイ・演出系（簡易・必要なら個別作成）
これらは全画面UIではなく重ね表示の演出。基本は各画面ブリーフに内包でOK。単体で作る場合のみ依頼:
- **ターン表示演出**: 「— ターン N —」が左→右にスライドしてフェードアウト。
- **バズ演出**: 「バズ発生！/大バズ発生！/炎上発生！」のスライドバナー＋アイコン(炎/虹)。
- **営業演出**: 暗転＋コインがポップ。
- **ターン行動ヒント**: 最大3枚のヒントカード（アイコン＋テキスト）を画面隅に。
- **ローディング**: スピナー＋ステータス文＋フェードアウト。
- **汎用ポップアップ**: 小/中/大の確認ダイアログ（タイトル・本文・OK/キャンセル）。
- **アイテム詳細ポップアップ**: 市場分析（需要/基準価/現在価格/売率/前ターン販売/人気）。
