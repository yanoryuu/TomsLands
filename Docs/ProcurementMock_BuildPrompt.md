# 仕入れ画面（鍛冶屋／トレード端末）ビルドプロンプト（claudeDesign 用）

別Claude（claude.ai のアーティファクト等）に、このプロンプト＋素材（キャラ立ち絵・UIフレーム/ボタン・背景）を渡して使う。

```
ファンタジーRPGショップゲームの「仕入れ画面」を、株式トレード端末風に統合したUIの
インタラクティブHTMLモック（1画面）を Artifact として作ってください。
添付した画像素材（キャラ立ち絵 / UIフレーム・ボタン素材 / 背景画像）を使ってください。

## 重要な制約
- 単一の自己完結HTML（CSS/JSインライン）。外部URL・CDN・外部フォント禁止。
- 添付画像は data: URI（base64）でインライン埋め込み。
- 文言は日本語。横長デスクトップ（16:9）。ページ自体は横スクロールさせない。
- 独自装飾は足さない。添付UI素材（フレーム/ボタン/背景）の見た目を主役に。

## 素材の割り当て
- 背景画像 → ページ全体の背景。
- キャラ立ち絵 → 画面左カラムに店主として配置。上に会話フキダシ（「いらっしゃい、何を仕入れる？」等）。
- UIフレーム・ボタン素材 → 各パネル枠・タブ・「仕入れる」ボタンに適用（角が伸びる素材は CSS border-image で9-slice的に）。
- アイテムアイコンは無し → 属性カラー縁取りのグレー枠プレースホルダーで代用。

## レイアウト（4領域）
- 上部: 次ダンジョン情報バナー（全幅）。ダンジョン名「火の洞窟」/「弱点：火」/「あと2ターン」/「勇者Lv.5 武器:火の剣 / 防具:鉄の鎧」。
- 左(~22%): 店主キャラ立ち絵＋会話フキダシ。
- 中央(~33%): 銘柄一覧（株のウォッチリスト風）。上に「武器/防具」タブと「並べ替え:収益/需要/価格」ドロップダウン。各行: アイコン枠(属性色縁)・名前・価格＋前回比矢印(↑赤↓青→灰)・需要%＋細い横バー・在庫×数・「人気」「品薄」バッジ。1行は選択ハイライト。
- 右(~45%): 選択銘柄の詳細。大アイコン＋名前＋属性。価格チャート(インラインSVGの折れ線、価格=金色ライン/需要=水色補助ライン/薄グリッド)。市場分析チップ(需要%/基準価/現在価格/売率/前ターン販売✓/おすすめ度)。注文(数量スライダー→合計ライブ更新、仕入れるボタン)。

## 動作仕様
- 行クリック → 右詳細更新＋選択ハイライト。初期は先頭銘柄を自動選択。
- 武器/防具タブでリスト差し替え。
- 並べ替え「収益」=需要×価格×売率の降順(既定)/「需要」/「価格」。
- 数量スライダー → 合計=価格×数量 をライブ更新。仕入れるで在庫+＆トースト。
- おすすめ度 = 期待収益(需要×価格×売率)。次ダンジョン弱点「火」に一致する属性は×1.5で優遇。
```
