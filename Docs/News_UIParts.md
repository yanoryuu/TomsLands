## 0. 方針

**採用するのは C案のレイアウトだけ。見た目は既存の絵柄に全面的に合わせる。**

C3モックはダークスレート＋真鍮＋明朝＋木版画で、現行UI（茶系・角丸・唐草・丸ゴシック）と別物だった。
このまま作るとこの画面だけ別ゲームになる。

**新聞らしさは、色と書体ではなくレイアウトで出す。**
茶色の枠の中に**明るいベージュの紙面**を置き、段組・罫線・見出しの階層・写真枠で「紙」を表現する。
書体は既存の M PLUS Rounded 1c Bold のまま。`占い屋` の「現在のトレンド」見出し下にある細い罫線が、
そのまま新聞の罫として使える。

**立ち絵は置かない。** 人物を出さず紙面に集中させる。他の店画面にある下部のメッセージボックスも置かない
（話す相手がいないため）。その分の縦幅を紙面に回す。

## 6. 発注時の注意

- **可変の中身をパーツに焼き込まない。** 社カードに評価の星を描き込むと、社ごとに違う値を表現できなくなる。
  カードは空の枠として作り、星は別パーツとして実行時に並べる。同様に、記事ボックスに見出しや本文を描かない
- **9スライス指定のものは、角・辺が伸びても崩れない元画像**で作る。記事本数や社数で高さが変わる
- 状態違い（`−0` / `−1`）は**同一サイズ・同一位置**で作る。差し替えでズレないこと。
  **2状態を1枚の絵に並べて描いてから切り分ける**と確実に揃う

### 生成パイプライン（AI生成する場合）

1. **純緑（RGB 0,255,0）背景**で生成する。透過指定で生成すると、アルファに強いグローが焼き込まれる
   （実測でアルファ160〜254の帯が18万ピクセル＝どの背景でも輪郭が滲む）
2. `scratchpad/deck/chromakey.js <入力> <出力> green` で抜く。緑の除去・縁の緑かぶり補正・余白トリムまで行う
3. 2状態を1枚で描いた場合は `split2.js`（横並び）/ `splitv.js`（縦並び）で切り分ける。
   `splitv.js` はトリムしないので**同一サイズが保たれる**
4. 結果のアルファは 0 か 255 のみになる。Unity 側の縮小でアンチエイリアスがかかるので問題ない

**単純な幾何形状は AI に描かせず SVG で生成する。** 罫線・タブ・バッジ・細線の枠は、
生成モデルに指示しても形が安定しない（面タブは3回とも肩の付いた輪郭になった）。
`tabs.js` / `geo.js` / `rules.js` のように SVG を書いて `sharp` でラスタライズすれば、
寸法も色も完全に一致する。**装飾のあるもの（紋章・唐草・リボン・星・写真枠）だけ AI で描く。**

色の定数（SVG側と揃えること）:
`OUTLINE #4A2E1E` / `CREAM #F7EBD2` / `CREAM2 #EEDDBC` / `BROWN #8B5A32` /
`BROWN_D #5E3B22` / `BEIGE #E5CFA6` / `GOLD #E8A33D` / `RED #A8332B`
- `22 状態バッジ` は3状態、`26 Heatドット` は5枚。他は2状態まで
- `6 社の紋章` は5種。立ち絵を置かないぶん、**社の個性は紋章と題字だけで表現する**ので描き分けを効かせる
- `19 スクラップ台紙` と `8 紙面ベース` は質感を変える（コルク／紙）。同じ茶系でも素材が違うと分かること
- `17 お詫びと訂正枠` は**目立たせない**。見落とすことが仕様

## 7. 付随して直すもの

`占い屋` 画面は現在「現在のトレンド／武器ランキング／次のダンジョン情報／おすすめ武器」を表示しており、
`News_Spec.md` の C5・C6 で**消すと決めた情報そのもの**。

新規パーツは不要（既存パーツの再配置で足りる）が、**中身の作り直しが必要**。
預言者は「選んだ1銘柄の Trend を ↑↑/↑/→/↓ の粗い記号で有料観測」へ変わるため、
既存の `上昇.png` / `下落.png` / `維持.png` をそのまま使える。
