====================================================
  TurnEndSummary UI設計書
====================================================

■ 概要
ターン終了時に表示される売上サマリー画面のUI設計書です。
プレイヤーが「次のターン」ボタンを押した際に表示され、
売上実績の確認と次ターンへの進行を管理します。


====================================================
■ 全体構成
====================================================

メインパネル: turnEndSummaryPanel
  - 役割: サマリー画面全体を包含するパネル
  - 表示タイミング: ターン終了時
  - 位置: 画面中央（モーダル表示推奨）


====================================================
■ 必要なUI要素一覧
====================================================

【1. ヘッダー部分】
  - タイトルテキスト: "ターン終了サマリー" または "売上報告"

----------------------------------------------------
【2. サマリー情報表示エリア】
  以下の3つのテキスト要素が必要:

  ● totalRevenueText
    - 種類: TextMeshProUGUI
    - 表示内容: 総売上金額
    - 表示例: "1,250G"
    - ラベル: "売上合計:" など

  ● totalSoldCountText
    - 種類: TextMeshProUGUI
    - 表示内容: 総販売個数
    - 表示例: "15個"
    - ラベル: "販売数合計:" など

  ● daysUntilBattleText
    - 種類: TextMeshProUGUI
    - 表示内容: 次の配信（バトル）までの日数
    - 表示例: "あと3ターン" または "予定なし"
    - ラベル: "次の配信まで:" など

----------------------------------------------------
【3. アイテム別詳細リスト】

  ● contentParent (リストの親オブジェクト)
    - 種類: Transform
    - 役割: 動的生成される行の親オブジェクト
    - 推奨: ScrollViewのContent部分
    - レイアウト: VerticalLayoutGroup推奨

  ● rowPrefab (各アイテム行のプレハブ)
    以下の4要素を1行に含むプレハブ:

    ○ itemNameText
      - 種類: TextMeshProUGUI
      - 表示内容: アイテム名
      - 表示例: "鉄の剣", "体力ポーション"

    ○ soldCountText
      - 種類: TextMeshProUGUI
      - 表示内容: 販売個数
      - 表示例: "3個"

    ○ revenueText
      - 種類: TextMeshProUGUI
      - 表示内容: そのアイテムの売上
      - 表示例: "450G"

    ○ trendText
      - 種類: TextMeshProUGUI
      - 表示内容: 需要トレンド
      - 表示パターン:
        ↑ (赤色)         … 需要上昇中
        → (デフォルト色)   … 需要安定
        ↓ (青色)         … 需要下降中

----------------------------------------------------
【4. アクションボタン】

  ● confirmButton
    - 種類: Button
    - テキスト: "確認" または "次のターンへ"
    - 機能: サマリー確認後、実際にターンを進行
    - 位置: パネル下部中央推奨


====================================================
■ 推奨レイアウト構成
====================================================

  ┌─────────────────────────────────┐
  │          ターン終了サマリー           │  ← ヘッダー
  ├─────────────────────────────────┤
  │ 売上合計: 1,250G   販売数: 15個      │  ← サマリー情報
  │ 次の配信まで: あと3ターン              │
  ├─────────────────────────────────┤
  │                                 │
  │   アイテム │ 個数 │ 売上 │ 需要    │  ← テーブルヘッダー
  │  ─────────┼──────┼──────┼──────  │
  │   鉄の剣   │  3個 │ 450G │  ↑     │  ← 行プレハブ
  │   薬草     │  5個 │ 100G │  →     │
  │   盾      │  2個 │ 700G │  ↓     │
  │   ...     │  ... │  ... │  ...   │
  │                                 │  ← ScrollView対応
  ├─────────────────────────────────┤
  │          [次のターンへ]             │  ← 確認ボタン
  └─────────────────────────────────┘


====================================================
■ デザイン上の注意点
====================================================

  1. 可読性
     - 数字が見やすいフォントサイズと色を使用

  2. スクロール対応
     - アイテム数が多い場合に備えてScrollView推奨

  3. トレンド表示
     - 矢印の色分けで直感的に需要変化を表現
     - ↑赤 / →デフォルト / ↓青

  4. モーダル感
     - 重要な情報なので、背景を暗くするなどして注目を集める

  5. レスポンシブ
     - 異なる画面サイズでも適切に表示されるように


====================================================
■ 補足: プログラマー向け接続情報
====================================================

  必要なコンポーネント:
    1. メインパネルに TurnEndSummaryView スクリプトをアタッチ
    2. 行プレハブに TurnEndSummaryRowUI スクリプトをアタッチ
    3. GamePanelManager の turnEndSummaryPanel に
       メインパネルを設定

  表示制御:
    - GamePanelManagerが自動的にパネル表示/非表示を管理
    - 他のパネルは自動的に非表示になる
