え====================================================
  Result（リザルト画面） UI設計書
====================================================

■ 概要
ゲーム全体の最終結果を表示するリザルト画面のUI設計書です。
GameFlowの全ターンが完了した時に ResultScene へシーン遷移し、
プレイヤーの経営成績を評価・表示します。

表示タイミング: GameFlowManager.NextTurn() で全ターン完了時
             → SceneTransitionService.GoToResult() で ResultScene へ遷移


====================================================
■ 全体構成
====================================================

シーン: ResultScene（Assets/Scene/ResultScene.unity）
  - BattleScene / EventScene と同様の別シーン方式
  - ResultLifetimeScope を空の GameObject にアタッチ
  - TomsShop からセーブデータ経由でデータを受け渡し

メインパネル: ResultPanel
  - 役割: リザルト画面全体を包含するパネル
  - スクリプト: ResultView をアタッチ


====================================================
■ 必要なUI要素一覧
====================================================

【1. ヘッダー部分】
  - タイトルテキスト: "経営結果" または "RESULT"

----------------------------------------------------
【2. ランク表示エリア（最も目立つ位置に）】

  ● rankText
    - 種類: TextMeshProUGUI
    - 表示内容: 評価ランク（S / A / B / C / D）
    - フォントサイズ: 大きめ（72〜120pt推奨）
    - 色: ランクに応じて自動変更
      S → ゴールド (1.0, 0.84, 0.0)
      A → 赤 (0.9, 0.3, 0.3)
      B → 青 (0.3, 0.6, 0.9)
      C → 緑 (0.3, 0.8, 0.3)
      D → グレー (0.5, 0.5, 0.5)
    - 位置: パネル上部中央

  ● commentText
    - 種類: TextMeshProUGUI
    - 表示内容: ランクに応じたコメント
    - 表示例:
      S → "伝説の商人！ トムの名は大陸中に轟いた！"
      A → "素晴らしい経営手腕！ 街一番の店になった！"
      B → "堅実な商売で利益を出せた。立派な商人だ。"
      C → "なんとか黒字で終了。まだまだ伸びしろがある。"
      D → "赤字経営…。次はもっと上手くやれるはず！"

----------------------------------------------------
【3. 資産情報エリア】

  ● finalMoneyText
    - 種類: TextMeshProUGUI
    - 表示内容: 最終所持金
    - 表示例: "15,000G"
    - ラベル: "最終所持金:"

  ● moneyDifferenceText
    - 種類: TextMeshProUGUI
    - 表示内容: 初期所持金との差分
    - 表示例: "+5,000G" (黒字は緑色) / "-2,000G" (赤字は赤色)
    - ラベル: "収支:"

  ● stockValueText
    - 種類: TextMeshProUGUI
    - 表示内容: 在庫アイテムの総資産額
    - 表示例: "8,500G"
    - ラベル: "在庫資産:"

  ● netWorthText
    - 種類: TextMeshProUGUI
    - 表示内容: 純資産（所持金 + 在庫資産）
    - 表示例: "23,500G"
    - ラベル: "純資産:"
    - ※ 評価ランクの算出基準

----------------------------------------------------
【4. ゲーム情報エリア】

  ● totalTurnsText
    - 種類: TextMeshProUGUI
    - 表示内容: 到達ターン数
    - 表示例: "12ターン"
    - ラベル: "経過ターン:"

  ● blacksmithLevelText
    - 種類: TextMeshProUGUI
    - 表示内容: 最終鍛冶屋レベル
    - 表示例: "Lv.3"
    - ラベル: "鍛冶屋レベル:"

  ● totalRemainingStockText
    - 種類: TextMeshProUGUI
    - 表示内容: 残りアイテム総数
    - 表示例: "25個"
    - ラベル: "残在庫数:"

----------------------------------------------------
【5. アイテム別在庫詳細リスト】

  ● itemListParent (リストの親オブジェクト)
    - 種類: Transform
    - 役割: 動的生成される行の親オブジェクト
    - 推奨: ScrollViewのContent部分
    - レイアウト: VerticalLayoutGroup推奨
    - ※在庫が1以上のアイテムのみ表示

  ● itemRowPrefab (各アイテム行のプレハブ)
    アタッチスクリプト: ResultItemRowUI
    以下の5要素を1行に含むプレハブ:

    ○ itemNameText
      - 種類: TextMeshProUGUI
      - 表示内容: アイテム名
      - 表示例: "鉄の剣", "革の鎧"

    ○ stockText
      - 種類: TextMeshProUGUI
      - 表示内容: 残在庫数
      - 表示例: "3個"

    ○ priceText
      - 種類: TextMeshProUGUI
      - 表示内容: 現在単価
      - 表示例: "150G"

    ○ valueText
      - 種類: TextMeshProUGUI
      - 表示内容: 在庫資産額（単価 × 残在庫数）
      - 表示例: "450G"

    ○ demandText
      - 種類: TextMeshProUGUI
      - 表示内容: 需要トレンド
      - 表示パターン:
        ↑ (赤色)         … 需要上昇中（0.7以上）
        → (デフォルト色)   … 需要安定
        ↓ (青色)         … 需要下降中（0.3以下）

----------------------------------------------------
【6. アクションボタン】

  ● goToTitleButton
    - 種類: Button
    - テキスト: "タイトルへ戻る"
    - 機能: タイトルシーン（Start）へ遷移
    - 位置: パネル下部右側

  ● retryButton
    - 種類: Button
    - テキスト: "もう一度遊ぶ"
    - 機能: タイトルへ戻る（タイトルで「初めから」を選ぶ運用）
    - 位置: パネル下部左側

====================================================
■ 評価ランクの基準
====================================================

  純資産（所持金 + 在庫資産額）を初期所持金で割った倍率で判定:

  ランク │ 倍率
  ───────┼──────
    S    │ 5.0倍以上  (50,000G以上)
    A    │ 3.0倍以上  (30,000G以上)
    B    │ 2.0倍以上  (20,000G以上)
    C    │ 1.0倍以上  (10,000G以上)
    D    │ 1.0倍未満  (10,000G未満)

  ※ 初期所持金 = GameConst.InitMoney = 10,000G


====================================================
■ デザイン上の注意点
====================================================

  1. ランク表示を最も目立たせる
     - 大きなフォントサイズ、色分け、
       可能であればアニメーション演出（スケールイン等）

  2. 収支の色分け
     - 黒字（+）は緑色、赤字（-）は赤色で直感的に

  3. スクロール対応
     - アイテムリストはScrollViewで対応

  4. モーダル感
     - 背景を暗くして注目させる

  5. ボタンの配置
     - 2つのボタンを下部に並べる


====================================================
■ 補足: プログラマー向け接続情報
====================================================

  シーン構築手順:
    1. ResultScene を開く（Assets/Scene/ResultScene.unity）
    2. 空の GameObject に ResultLifetimeScope をアタッチ
    3. Canvas 配下に ResultPanel を作成し ResultView をアタッチ
    4. ResultLifetimeScope の resultView に ResultView を設定
    5. 行プレハブに ResultItemRowUI スクリプトをアタッチ
    6. Build Settings に ResultScene を追加

  データの流れ:
    TomsShop シーン
      → GameFlowManager.TransitionToResult()
        → TomsModel.SavePlayerMoney() / ItemModel.SaveData()
        → SceneTransitionService.GoToResult()
    ResultScene
      → ResultLifetimeScope が TomsModel / ItemModel を生成
        → コンストラクタでセーブデータを自動ロード
      → ResultPresenter.Start() → Entry()
        → ResultModel.BuildStatistics() で統計集計
        → ResultView.UpdateContent() で UI 更新

  表示制御:
    - ResultScene はシーン全体がリザルト画面
    - Start() で即座に Entry() が呼ばれ、統計表示される
    - ボタン押下で GoToTitle() でタイトルシーンへ遷移

  依存関係:
    - ResultModel → TomsModel, ItemModel
    - ResultPresenter → ResultView, ResultModel, SceneTransitionService
    - すべて ResultLifetimeScope で DI 登録
