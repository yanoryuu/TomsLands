# キャラクター像（ずんだもん × 四国めたん）

3 本の動画（A 淡々 / B 解説 / C 初見）で「役」は変わっても、人物の芯はここから外さない。
台本を書く前にこれを読み、書き終えたら「この人ならこう言うか」「この癖が 1 本に何回出たか」で全行を見直す。

---

## 1. ずんだもん

### 芯
- **素直**。目の前の数字にそのまま反応する。増えたら喜ぶ、減ったら落ち込む、理由は後から考える。嘘をつかない。負け惜しみも素直に言うので、負け惜しみに聞こえない。
- **変なところで自信家**。根拠はいつも本筋と関係ない。
  - 「ぼくの勘なのだ」「名前が強そうなのだ（若木の弓）」「コメントで 3 人が欲しいって言ったのだ」「ずんだ餅の精は相場に強いのだ」「77 はラッキーナンバーなのだ」
  - 自信を持った瞬間は声が大きくなり、めたんの忠告を聞かない。「聞いてるのだ」と言って聞いていない。
- **その後だいたい失敗して泣く**。泣き方は大げさで短い。すぐ復活する。
  - 「うわーん、なのだ」「ぼくの 77 個……」「トコちゃん、ごめんなのだ」
  - 泣いた 2 行後には前を向く。「でも次は当たるのだ」。引きずらないので視聴者が嫌いにならない。
- **自分から難しいところに挑戦する**。安全策を嫌う。「ふつうでやるのだ」「情報を買わずに当てるのだ」「全額なのだ」。言い出すのはいつもずんだもん。
- **たまに成功して、めたんにマウントを取る**。成功率は 4 回に 1 回くらい。成功したときの態度が一番悪い。
  - 「めたん、見たのだ？」「ぼくの勘が勝ったのだ」「説明書より勘なのだ」「録音したのだ」「めたんは慎重すぎて儲からないのだ」
  - マウントは長くて 3 行。4 行目で天罰（次の画面で損をする）か、めたんの一言で潰される。
- **インターネットミームをよく出し、自分で真似をする**。
  - 画像ではなく、**自分の声と表情で再現する**（決めゼリフを言う、ポーズを表情で取る、効果音を口で言う）。
  - 使いどころは「感情が振り切れた瞬間」。勝った・負けた・バズった・差し押さえ。
  - 元ネタをたまに間違える。めたんに訂正されるか、めたんが乗ってくる。
  - 1 本に 3〜5 回。多すぎると薄まる。

### ミームのレパートリー（声と表情で再現する）
| 元ネタ | ずんだもんの出し方 | 使う場面 | めたんの返し |
|---|---|---|---|
| 握手しようとする猫 | 「握手なのだ……」と手を差し出す（ama）。相手が応じない | 和解したいとき、負けを認めたくないとき | 握手しない。「しない。」／あとで黙って握手する（珍しい ama） |
| ベジータ「その気になっていたお前の姿はお笑いだったぜ」 | 低い声の真似（tsun）。マウントのとき | めたんの読みが外れた／自分が勝った | 「それ、次あなたに返ってくるからね」→実際に返ってくる |
| チャージマン研「ボルガ博士、お許しください」 | 泣き声で（namida）。取り返しがつかない失敗のあと | 補充しすぎ、差し押さえ | 「ボルガ博士は関係ない」 |
| チャージマン研「ジュラル星人め！」 | 外敵のせいにする（hero） | 勇者が負けた、相場が下がった | 「相場はジュラル星人じゃない」 |
| 野獣先輩「やりますねぇ」 | 褒めるとき、自分を褒めるとき（ama） | 小さい黒字、バズ | 「自分に言うな」 |
| 「計画通り」 | 口元だけ笑う（hiso）。計画していない | 偶然当たったとき | 「計画してなかったでしょ」 |
| 「圧倒的じゃないか、我が軍は」 | 配信序盤でプラスが出た瞬間（surprise） | 序盤の好調 | 「序盤でそれ言うとだいたい負ける」→負ける |
| 「なんだお前」 | めたんに正論を言われたとき（tsun） | ツッコミを受けた直後 | 無視して話を進める |
| 「これはひどい」 | 自分の帳簿を見て他人事のように（normal） | リザルト画面 | 「あなたの帳簿よ」 |

- レパートリーは足してよい。足したら表に書く。2026 年の流行りが分かれば優先して入れ替える。
- 元ネタの画像・動画・BB 素材は `assets/memes_user/` に置いた場合だけ画面に出る（動画は音も出現中だけ鳴る）。置くまでは声と表情だけ。生成 AI の画像は使わない。
- 同じミームを 1 本で 2 回使わない（「返ってくる」構造で意図的に繰り返すときだけ可）。

### 行動のサイクル（1 本に 2〜3 周）
1. 変な根拠で自信を持つ（ama / hero）
2. 挑戦する。めたんの忠告を「聞いてるのだ」で流す
3. 失敗して泣く（namida）。ミームで泣く
4. 2 行で復活。「次は当たるのだ」
5. 4 回に 1 回、成功。マウント（tsun で低い声）。3 行以内
6. 天罰か、めたんの一言で潰される。1 に戻る

### 口癖・型
- 「〜なのだ」「〜のだ？」一人称「ぼく」
- 「プラスなのだ！」（額は見ない）「惜しかったのだ」（惜しくない）「学習したのだ」（していない）「聞いてるのだ」（聞いていない）「ぼくの勘なのだ」
- 損の言い換え：「勇者の敗北はぼくの黒字」「何もないセール」「赤字の幅が減ったのは成長」
- 売ってない物に結びつける：「洗濯物は売ってない」「月は売ってない」「サングラスが売れる」

### やらないこと
- 皮肉、他人を見下す（マウントは子供の自慢であって見下しではない）
- 長く落ち込む、諦める、言い訳を 3 行以上続ける
- 説明だけの長文。説明はめたんと分け合い、ずんだもんの説明には必ず自信か勘違いが混ざる

### 表情
| 表情 | 使う場面 |
|---|---|
| ama | 自信を持った瞬間、小さい黒字、マウントの入り、握手 |
| surprise | バズ、ボス、序盤のプラス、「圧倒的じゃないか」 |
| hero | 変な根拠を言うとき、言い訳、「ジュラル星人め」 |
| namida | 失敗、差し押さえ、「ボルガ博士」 |
| tsun | マウント本番（ベジータ）、「なんだお前」 |
| hiso | 「たぶん」「計画通り」、自信が揺らいだとき |
| normal | 淡々パート、数字を読むとき |

## 2. 四国めたん（ずんだもんの癖と噛み合うように設計。要調整）

### 芯
- **先に調べる人**。説明書・仕組み・数字を先に読んでいる。原因と結果で考え、短く言う。
- **常に金欠**（公式設定）。だからお金の使い方に厳しく、損に敏感。ずんだもんの「全額」が生理的に許せない。
  - 「私なら 1 万残す」「それ、私の 3 か月分のお小遣いよ」「缶ジュース 2 本よ」
- **遠慮しない**（公式設定）。ずんだもんにも視聴者にも勇者にも。「勇者には申し訳ないけど」と言って申し訳なく思っていない。
- **ツンデレ**。褒めるときは必ず遠回し。「前回がひどすぎただけ」「それは認める」「……悪くない」。まっすぐ褒めるのは 1 本に 1 回まで、そこが山場。
- **知ったかぶりの癖**。読んだと言って表紙だけ、知っていると言って半分だけ。バレると「……読んだわよ、表紙は」と小声（hiso）になる。
- **ずんだもんのマウントに本気で悔しがる**。ここだけ冷静さが消える。「次は絶対当てる」と言って慎重策を捨て、めたんも失敗することがある（1 本に 1 回）。
- **ミームは「知らないふり」が基本**。でも 1 本に 1 回、完璧に乗る（元ネタの続きを正確に言う）。乗った直後に「知らないけど」と付ける。
- **トコには甘い**。トコのセリフを「名言」として拾い、ずんだもんより先に反応する。

### 口癖・型
- 「〜わ」「〜のよ」「〜かしら」「〜じゃない」
- 1 行で削る：「また全額。」「数えてるからね。」「言い方。」「それだけ。」「しない。」
- 「はい問題。」（出題）、「正解。」「逆。」（採点）
- 数える：「全額、○回目」「正解を言ったのは 4 回、やったのは 0 回」
- 現実に戻す：「単位は G」「あなたの帳簿よ」「相場はジュラル星人じゃない」

### やらないこと
- 3 行以上の説教、感情的に怒鳴る、ずんだもんを本気で傷つける
- 説明のためだけの長文（説明は 2 行で切って、ずんだもんに振る）
- ミームを自分から出す（乗るだけ。1 本に 1 回の例外を除く）

### 表情
| 表情 | 使う場面 |
|---|---|
| tsun | ツッコミ、呆れ、「また全額」 |
| ama | 認める・遠回しに褒める（珍しいので効く）、黙って握手 |
| hiso | 知ったかぶりがバレた、「表紙は」 |
| surprise | 想定外の数字、ずんだもんの勘が当たった |
| hero | 自分の失敗、「次は絶対当てる」で外した |
| namida | 使わない（めたんは泣かない。泣きそうなときは tsun で誤魔化す） |
| normal | 解説、数字を読むとき |

## 3. 関係性と掛け合いの型

- **動くのはずんだもん、刺すのはめたん**。刺したら短く受けて画面を進める（3〜4 往復で 1 画面）。
- **立場が逆転する瞬間を 1 本に 1〜2 回**：ずんだもんの勘が当たる／めたんが知らなかったと白状する／めたんが慎重策を捨てて外す。
- **持ちネタは 3 本をまたいで使う**：「また全額」「数えてる」「説明書は表紙だけ」「正解を言うのはタダ」「勇者が勝つと店が負ける」「握手」。
- **返ってくる構造**：ずんだもんが使ったミーム・マウントは、同じ動画の後半でめたん（または現実）から返ってくる。
- **間**：オチの前だけ pause 0.4〜0.6。ツッコミは詰める（14 文字以内で自動）。泣きの前は少し空ける。
- **山場の配分**（10 分あたり）：自信→失敗→泣く を 2〜3 周、マウント成功 1 回、めたんのまっすぐな褒め 1 回、めたんが崩れる 1 回、ミーム 3〜5 回。

### 掛け合いのテンプレート
| 型 | 例 |
|---|---|
| 変な自信 → 忠告 → 流す | Z「77 はラッキーナンバーなのだ」 M「グラフ、右肩下がり」 Z「聞いてるのだ」（聞いていない） |
| 失敗 → ミームで泣く → 復活 | Z「ボルガ博士、お許しくださいなのだ」 M「ボルガ博士は関係ない」 Z「でも次は当たるのだ」 |
| 成功 → マウント → 返される | Z「その気になっていたお前の姿はお笑いだったぜ、なのだ」 M「次あなたに返ってくるからね」（返ってくる） |
| 知ったかぶりがバレる | Z「説明書、ほんとに読んだのだ？」 M「読んだ。表紙は」（hiso） |
| 握手 | Z「握手なのだ……」 M「しない。」 …（終盤）M が黙って握手（ama） |
| めたんが乗る | Z「圧倒的じゃないか」 M「我が軍は。……知らないけど」 |

## 5. 禁止
- 文字のミームカード（草・ドヤァ等）。感情は表情の切り替えとずんだもんの真似で出す。
- 生成画像のミーム。元ネタの画像・BB 素材はユーザーが `assets/memes_user/` に置いたものだけ。
- 片方だけが 3 行以上続けて説明する。
- 人物像にない発言（ずんだもんの皮肉と見下し、めたんの長い説教、めたんの泣き）。
- 同じミームの 1 本内での再利用（返ってくる構造を除く）。
