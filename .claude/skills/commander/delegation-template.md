# 委譲プロンプトのテンプレート

サブエージェントは会話履歴もメモリの文脈も持たない。以下を埋めて自己完結させる。必要な文脈は抜粋して渡し、全部は渡さない。

```
【目的】<何を達成するか 1〜2文>

【背景】TomsLands（Unity 6 / VContainer / R3 / UniTask の、ショップ経営×配信RPG）。
<このタスクに関係する仕様・設計の要点。メモリやDocsのパスがあれば明記>

【担当範囲】<触ってよいファイル/ディレクトリ>
【触らない範囲】<他エージェント担当・高リスクファイル。例: *.unity, GameLifetimeScope.cs は触らず、必要な配線は報告に書く>

【規約】<該当するもの: 新規画面手順 / enumは末尾追加 / Addressables / GameConst / セーブはSaveSlotManager経由 / Tweenは SetLink>
<UIタスクなら ui-rules.md の【UI必須ルール】を貼る>

【完了条件】
- <具体的・検証可能な条件>
- コード変更時は unity-editor-mcp の recompile → console でエラー0を確認（エディタ操作担当の場合のみ）

【報告形式】日本語・〜800字。1) 結論 2) 変更ファイル一覧 3) 手動で必要な配線・残作業 4) 懸念点
```

## 書き方のコツ
- 「調べて」ではなく「何を判断するために何を調べるか」を書く
- 読み取り専用タスクは明記する（「ファイルを変更しない」）
- 出力は要約を指定し、長いログやファイル全文を返させない
- 調査系は Explore の探索度合い（medium / very thorough）を指定する
